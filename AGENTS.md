# Ashvault

Local Unity desktop ARPG prototype. Read PROJECT_STATE.md before work.
Keep gameplay near 1,000–1,500 lines and custom components few. No backend,
networking, account systems, inventory grid, or generated world. Keep code
Mac/Windows compatible. Visual children must remain replaceable independently
of colliders and gameplay. Do not use paid GPU compute.

Unity project: `Game/`. Prefer Unity CLI for editor/scene operations.
Run `.quality-gate.json` commands and a visible gameplay check before claiming playable.
