# ARMAGEDOM browser client

Approved Three.js migration; independent `Web/` client preserving `Game/`, frozen
Mac and immutable Unity006. One Westminster mixed encounter is the first delivery
checkpoint; existing south/east data and World loader are retained for the next
integration checkpoint. No backend or new content.

From this directory: `npm ci`, `npm test`, `npm run build`. Serve `dist/` as a
versioned static directory with a trailing slash. Relative URLs support the
existing HTTPS preview host. `npm run dev` is local development only. `?touch=1`
shows the touch layout for desktop review; this is not physical-phone validation.

35 Node checks cover combat timing, targeting, guard/parry, dodge, projectiles,
wave progression/loot, independent input pointers, cosmetic IK, registered world
collision/crop/depth/disposal and all26 audited landmarks. Actual production
browser and named physical-phone evidence are separate gates. Original source
clips + Lead cosmetic overlays preserve attack/guard/foot/staff behaviour; these
must be judged at the fight camera, not inferred from passing numerical checks.

Only Westminster world assets and the current survivor/three enemy GLBs load
initially; Warlord reuses Orc. Assets are owned by Character, geometry/world data
by World; retain the full-source candidates and provenance. No placeholder roster
or material substitution. Lossless Meshopt/WebP derivatives total50.9MB versus86.6MB baseline; original rigs,
geometry, animation samples and decoded texture pixels are preserved. Physical
phone timing remains unverified; no3–4second phone claim is made.

Six actions: Slash/Stab/Heavy/Special/Dodge/Guard(timed Parry). WASD/mouse/Q/E/Space/F,
R retry. Touch movement and action-local aiming use separate pointer IDs; current
strike locks facing on activation, drag changes the following strike. Portrait and landscape are playable. Rotation clears held input and buffered attacks;
menu and background pause the fight. Audio uses
small local cues started/resumed only on a player gesture; Unity's reference has
no authored encounter audio, so this is not a source-audio parity claim.

Unity-specific `scripts/verify.py`/`smoke_mac.py` are inapplicable to this client:
no retiring Unity rebuild is required under THREEJS-MIGRATION.md. Six repository
sync checks pass. An inadvertently invoked old PlayMode gate was cancelled when
its Unity path was identified; no completed native test result is claimed.
